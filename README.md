## Installation

You can install `PSPclean` from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("ianmseddy/PSPclean")

## or, to get the latest development version:
pak::pak("ianmseddy/PSPclean@development")
```
