# PSPclean

<!-- badges: start -->
<!-- badges: end -->

Sources and standardizes permanent sample plot data

## Installation

You can install `PSPclean` from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("ianmseddy/PSPclean")

## or, to get the latest development version:
pak::pak("ianmseddy/PSPclean@development")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(PSPclean)
## basic example code
```
